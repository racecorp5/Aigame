# Chunk 01 — PILOT (split into single-file micro-prompts)

Six PNG deliverables, one prompt file each. Drag-and-drop workflow:

1. Pick a file from the table below.
2. Drag the `.md` file + **Image A** (System Breach style board) into your
   image generator.
3. Save the resulting PNG to the path the file specifies.
4. After all 6 are done, run `node tools/gen-manifests.js` from the repo
   root to auto-write the matching `.json` manifests.

**⚠ Do NOT attach Image B (the AGENT-01 sci-fi sheet).** It causes the
generator to produce a reference board instead of the deliverable PNG.
This is the same failure mode that ruined the first attempt — see
`prompts/_TROUBLESHOOTING.md`.

## Validation order

Run them in this order — each builds on the previous:

1. **01a Threadling sprite sheet** first. If this works, the spec is
   sound. If not, the 01a prompt needs tuning before continuing.
2. **01c Compute icon** second. Tiny, fast feedback on whether the
   palette is being respected.
3. **01b Threadling portrait** — confirms the same character renders
   consistently at portrait scale.
4. **01d TV enemy** — confirms the enemy sprite-sheet schema works
   (one-facing instead of four).
5. **01f Bit shard icon** — confirms the icon pipeline.
6. **01e BG_TV background** last — biggest file, hardest to nail.
   Save for last so you've already tuned the palette and style.

After all 6: `node tools/gen-manifests.js` from the repo root.

## What success looks like

- Six PNGs at the exact paths above, transparent backgrounds where
  required, exact pixel dimensions.
- Six matching JSONs auto-generated by the script.
- All six load in the game without "missing asset" errors.
- Threadling sprite renders at 44×66 on screen with no scaling artifacts.
- Animation rows scrub cleanly at the FPS the JSON declares.

If any file fails: stop, fix that prompt, retry. Do **not** generate
chunks 02–24 until all six pilot files validate in-engine. The same spec
mistake will multiply across 500 files.
